1. Purpose of the App

Focus Input is a macOS utility that lets you associate a preferred keyboard input source with an application. When a configured application becomes active, the App attempts to select the assigned input source.

Applications without a configured rule are left unchanged. The App does not continuously enforce a rule, and a manual input-source change remains untouched until you leave and return to the configured application.

2. Local Data and Privacy

Focus Input does not collect, transmit, sell, or share personal data. The App has no account system, networking, advertising, analytics, telemetry, cloud synchronization, or third-party crash-reporting service.

The App stores configured application bundle identifiers, application display-name snapshots, keyboard input-source identifiers, and App settings locally on your Mac using UserDefaults. This data is used only to provide the App's features.

The App observes foreground-application activation events locally so it can apply configured rules. It does not store an application-activity history and does not send application activity anywhere.

Because Focus Input does not operate a server or collect App data, there is no remote account or server-side data to delete.

3. Managing Local Data

You can remove an individual application's rule by choosing Do Not Manage in the App. You can remove all locally stored rules and settings by quitting the App and deleting its macOS preferences or application container.

Deleting the App may not automatically remove preferences retained by macOS. No consent withdrawal or deletion request needs to be sent to us because we do not receive or retain this data.

4. Application Selection and File Access

Focus Input can show supported applications that macOS reports as installed. You may also use the system application chooser to select an installed .app bundle.

When you choose an application, Focus Input uses read-only access to read its bundle identifier and display name. The App does not copy the selected application, modify it, inspect its documents, or retain access to its files.

5. Keyboard Input and System Permissions

Focus Input uses macOS Text Input Source Services to list enabled, selectable keyboard input sources, identify the current source, and select a configured source when an application becomes active.

The App does not read, record, or transmit keystrokes or typed text. It does not use Accessibility permission, AppleScript, or simulated keyboard shortcuts.

If you enable Launch at Login, Focus Input asks macOS to register the App as a login item. macOS manages that setting, and you can review or disable it in System Settings.

6. Functional Limitations

Focus Input requires supported input sources to be enabled in macOS. A configured rule may not work if its application or input source is removed, disabled, renamed, unavailable, or changed by macOS or another application.

Rules apply to an entire application, not to individual windows, documents, tabs, terminal sessions, editor panels, or text fields. The App does not restore the previous input source when you leave an application.
